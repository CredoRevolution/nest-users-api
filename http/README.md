# HTTP-запросы к API

Запросы для встроенного HTTP Client в PhpStorm. Postman не нужен.

## Быстрый старт

1. Подними базу и приложение: `docker compose up -d`, затем `npm run start:dev`
2. Открой любой `.http` файл
3. В правом верхнем углу редактора выбери окружение **dev**
4. Жми зелёный треугольник слева от нужного запроса

Начинай с `00-smoke.http` — там счастливый путь целиком, кнопкой «Run all requests in file» в шапке.

## Файлы

| Файл | Что внутри |
|---|---|
| `00-smoke.http` | Полный сценарий сверху вниз: регистрация → профиль → refresh → проверка ротации |
| `01-auth.http` | Регистрация, вход, обновление токенов + все негативные случаи |
| `02-profile.http` | `/profile/my`: чтение, обновление, мягкое удаление, и все способы не пройти гвард |
| `03-users.http` | Список пользователей: пагинация, фильтр по логину, попытки инъекций |
| `http-client.env.json` | Адрес сервера и тестовые пользователи |

Схему всех роутов с примерами можно посмотреть в Swagger: http://localhost:3000/docs

## Токены подставляются сами

После входа обработчик ответа кладёт токены в глобальные переменные:

```
client.global.set("access_token", response.body.access_token);
```

Дальше в любом запросе пишешь `Authorization: Bearer {{access_token}}` — подставится актуальный. Руками копировать ничего не надо.

Переменные живут между файлами и между запусками IDE. Посмотреть или почистить: **Tools → HTTP Client → Show HTTP Requests History**, либо файл `.idea/httpRequests/http-client.cookies` и хранилище переменных там же.

## Проверки в ответах

Блоки `> {% ... %}` после запроса — обычный JavaScript, который выполняется после ответа. `client.test(...)` создаёт именованную проверку, результат видно во вкладке **Tests** рядом с ответом: зелёная галочка или красный крест с твоим текстом ошибки.

Это не замена тестам на Jest (`npm test`), а ручная проверка, чтобы не разглядывать JSON глазами каждый раз.

## Своё окружение

`http-client.env.json` коммитится в репозиторий — там нет секретов. Если понадобится положить что-то приватное, создай рядом `http-client.private.env.json`, он уже в `.gitignore`.
